How to use Send to Kindle in Microsoft Edge

Updated October 25, 2026 · 5 min read

Short answer: the simplest way is to install a Send to Kindle extension from the Microsoft Edge Add-ons store, such as Leafpost, and click it on any article. Amazon's own Send to Kindle extension is published for Chrome; you can install it in Edge after allowing extensions from other stores, but it hasn't been updated since January 2024. For files, Amazon's web uploader at amazon.com/sendtokindle works in Edge like in any browser.

1. Install an extension from Edge Add-ons

Extensions from the Edge Add-ons store install in one click and update automatically. Leafpost is free there:

  1. Open Leafpost on Microsoft Edge Add-ons and click Get, then Add extension.
  2. Click the puzzle icon in the Edge toolbar and turn on Show in toolbar next to Leafpost.
  3. Sign in to Amazon in Edge, on the same store as your Kindle (amazon.com, amazon.co.uk, amazon.de…). Edge keeps its own sign-ins, so being signed in to Amazon in Chrome doesn't count.
  4. Open an article and click the Leafpost icon, or press Alt+Shift+K. Check the title and click Send to Kindle.

A minute later the article is on your Kindle as an e-book with its images, a cover and a table of contents. Right-click a link to send the page it points to, or select a passage to send just that part.

2. Use Amazon's Chrome extension in Edge

Edge is built on the same engine as Chrome, so most Chrome extensions run in it:

  1. Open edge://extensions and turn on Allow extensions from other stores.
  2. Go to the Chrome Web Store, open "Send to Kindle for Google Chrome" and click Get or Add to Chrome, then confirm.
  3. Sign in to Amazon when the extension asks.

Keep in mind that Amazon hasn't updated this extension since January 2024. Many people get stuck in a sign-in loop or find that it does nothing. If that happens, see why the Send to Kindle extension stops working.

3. Send PDFs and EPUBs with the web uploader

For files on your computer you don't need an extension at all:

  1. Open amazon.com/sendtokindle in Edge (or your own store, such as amazon.co.uk/sendtokindle) and sign in.
  2. Drag the file onto the page, or click the button to add your files.
  3. Click Send. The file is added to your Kindle library and syncs to your devices.

It accepts EPUB, PDF, Word documents and other common formats. Our guide to sending PDFs to Kindle explains when to keep the original layout. You can also email files to your Kindle address; here's how to find it.

Tips for Edge users

  • PDFs open in Edge's own viewer. Leafpost can send the PDF you are looking at. For PDFs opened from your computer (their address starts with file://), turn on "Allow access to file URLs" for the extension in edge://extensions.
  • Edge on Mac and Linux uses the same Edge Add-ons store, so the steps above work there too.
  • Sent documents appear in your Kindle library under Documents, not with your books. If you can't find one, see documents not showing up on Kindle.

FAQ

Is there an official Send to Kindle for Microsoft Edge?

Amazon offers Send to Kindle as a desktop app for Windows and Mac, a web uploader and an extension published for Chrome. In Edge you can use the web uploader, install the Chrome extension after allowing other stores, or use an extension from the Edge Add-ons store.

Do Chrome extensions work in Edge?

Most do, because Edge is based on Chromium. You have to allow extensions from other stores in edge://extensions first.

Can I send several articles as one book?

Yes. In Leafpost, save articles to your reading list during the day and send them together as one book with a chapter per article, or send all open tabs at once. See ways to send articles to Kindle.
