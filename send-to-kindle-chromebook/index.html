How to send articles, PDFs and EPUBs to Kindle from a Chromebook

Updated October 22, 2026 · 6 min read

Short answer: Amazon's Send to Kindle desktop app is only for Windows and Mac, but you don't need it on a Chromebook. To send a file (PDF, EPUB, Word), open amazon.com/sendtokindle in Chrome and drag it from the Files app. To send a web article, use a Chrome extension such as Leafpost, which works on ChromeOS like on any computer. Emailing the file to your @kindle.com address works too.

Most Kindle guides assume Windows or a Mac. On ChromeOS, some of the usual tools aren't available, but everything that runs in the browser works:

Send web articles with an extension

Chrome extensions from the Chrome Web Store run on ChromeOS the same way they do on Windows and Mac, so this is the quickest way to read blog posts, newsletters and news stories on your Kindle.

  1. Install Leafpost from the Chrome Web Store (it's free).
  2. Click the puzzle icon at the top right of Chrome and pin Leafpost so its icon is always visible.
  3. Make sure you are signed in to Amazon in Chrome, on the same store as your Kindle (amazon.com, amazon.co.uk, amazon.de…).
  4. Open an article and click the Leafpost icon, or press Alt+Shift+K. Check the title and click Send to Kindle.

The article arrives as a clean e-book with its images, a cover and a table of contents. You can also right-click a link to send the page it points to, or select a passage and send just that.

Amazon's own "Send to Kindle for Google Chrome" extension also installs on a Chromebook, but it hasn't been updated since January 2024 and often gets stuck asking you to sign in. If that happens, see why the extension stops working.

Send PDFs and EPUBs with the web uploader

For files saved on your Chromebook, Amazon's web uploader does the job of the desktop app:

  1. Open amazon.com/sendtokindle in Chrome (or your country's store, such as amazon.co.uk/sendtokindle) and sign in.
  2. Open the Files app and drag the file onto the page, or click the button to add your files and pick it from My files, Downloads or Google Drive.
  3. Click Send. The file is added to your Kindle library and syncs to your devices.

It accepts EPUB, PDF, Word documents and other common formats. For PDFs you can choose between keeping the original layout or adjustable text: our guide to sending PDFs to Kindle explains which to pick for your device.

If the PDF is already open in a Chrome tab, Leafpost can send it straight from there without saving it first. For PDFs opened from the Files app (their address starts with file://), turn on "Allow access to file URLs" for the extension in chrome://extensions.

Send by email from Gmail

  1. Find your Kindle's address, which ends in @kindle.com, and add your Gmail address to the approved list. Here's how to find and set it up.
  2. In Gmail, attach the file and send it to that address. Subject and body can be empty.

Email is handy for sending from your phone too, but it doesn't help with web articles: you would have to save each page as a PDF first, which reads poorly on an e-reader.

Read your documents on the Chromebook

Kindle for Web (read.amazon.com) works on any Chromebook, but it only shows books from the Kindle Store. Documents you send don't appear there. To read them on the Chromebook itself:

  1. Open the Play Store and install the Amazon Kindle app. Most Chromebooks from the last few years can run Android apps; if you don't see the Play Store, check Settings → Apps.
  2. Sign in with the same Amazon account.
  3. In the library, use the filter to show Documents.

If you still can't find something you sent, see documents not showing up on Kindle.

Copy files over USB

Connect your Kindle with a USB cable. On most Chromebooks it shows up in the Files app and you can copy EPUB or PDF files into its documents folder. The file stays on that one device only: it isn't added to your cloud library and won't sync to the Kindle app. Newer Kindles may connect in a different mode that some systems handle less smoothly, so if it doesn't appear, use the web uploader instead.

School and work Chromebooks

If your Chromebook is managed by a school or employer, the administrator may block extensions, the Play Store or USB drives. The web uploader and email usually still work because they run in a normal web page. If you can't install extensions, ask your administrator rather than trying to get around the restriction.

FAQ

Is there a Send to Kindle app for Chromebook?

No. Amazon's desktop app is only for Windows and Mac. On a Chromebook, use the web uploader, email or a Chrome extension instead; together they cover everything the app does.

Can I read Kindle books on a Chromebook?

Yes. Kindle for Web (read.amazon.com) shows the books you bought, and the Android Kindle app from the Play Store shows both books and the documents you sent.

Does the keyboard shortcut work on a Chromebook keyboard?

Yes. Alt+Shift+K works on ChromeOS. To change it, open chrome://extensions/shortcuts.

Why does my document not appear on my Kindle?

Check that you're signed in to the Amazon store where your Kindle is registered, and look under Documents in your library. Our troubleshooting guide covers the rest.
